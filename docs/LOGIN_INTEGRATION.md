# نظام تسجيل الدخول الموحد

## نظرة عامة

تم ربط نظام الأخبار بنظام الإدارة من خلال نظام تسجيل دخول موحد. الموظف يسجل دخول مرة واحدة باستخدام بيانات حسابه في نظام الإدارة، والتوكن يُستخدم مع جميع الطلبات.

## البنية

### الفرونت اند (Frontend)

#### صفحة تسجيل الدخول
- **الملف**: `frontend/src/components/auth/LoginPage.tsx`
- **الوظيفة**: عرض نموذج تسجيل الدخول وجلب التوكن من سيرفر الإدارة

#### خطوات تسجيل الدخول

1. **إدخال البيانات**
   - البريد الإلكتروني
   - كلمة المرور

2. **الاتصال بسيرفر الإدارة**
   ```
   POST https://media-center-management-system.onrender.com/api/auth/login
   {
     "email": "a.moqadi@najah.edu",
     "password": "a.mo1234"
   }
   ```

3. **الرد من السيرفر**
   ```json
   {
     "success": true,
     "data": {
       "token": "eyJhbGciOiJIUzI1NiIs...",
       "user": {
         "id": 57,
         "name": "أحمد موقدي",
         "email": "a.moqadi@najah.edu",
         "roles": [{ "id": 19, "name": "مخرج" }]
       }
     }
   }
   ```

4. **حفظ التوكن وبيانات المستخدم**
   - التوكن يُحفظ في `localStorage` تحت مفتاح `authToken`
   - بيانات المستخدم تُحفظ في `localStorage` تحت مفتاح `currentUser`

5. **جلب بيانات المستخدم الكاملة**
   ```
   GET https://media-center-management-system.onrender.com/api/auth/me
   Header: Authorization: Bearer TOKEN
   ```

6. **الرد**
   ```json
   {
     "success": true,
     "data": {
       "id": 57,
       "name": "أحمد موقدي",
       "email": "a.moqadi@najah.edu",
       "work_days": "الأحد,الاثنين,الثلاثاء,الأربعاء,الخميس",
       "start_time": "08:00",
       "end_time": "16:00",
       "is_active": true,
       "last_login": "2026-04-28T10:00:00.000Z",
       "roles": [{ "id": 19, "name": "مخرج" }],
       "permissions": ["orders.view", "tasks.view", "shootings.view", "content.view", "content.create", "programs.view"]
     }
   }
   ```

### API Service

#### دوال المصادقة
- `api.login(email, password)` - تسجيل الدخول
- `api.getMe()` - جلب بيانات المستخدم الحالي
- `api.logout()` - تسجيل الخروج

#### دوال إدارة التوكن
- `getAuthToken()` - الحصول على التوكن من localStorage
- `setAuthToken(token)` - حفظ التوكن في localStorage
- `clearAuthToken()` - حذف التوكن من localStorage
- `getCurrentUser()` - الحصول على بيانات المستخدم من localStorage
- `setCurrentUser(user)` - حفظ بيانات المستخدم في localStorage
- `clearCurrentUser()` - حذف بيانات المستخدم من localStorage

## تدفق الاستخدام

### 1. تسجيل الدخول الأول
```
المستخدم → صفحة تسجيل الدخول → إدخال البيانات → الضغط على "دخول"
↓
الفرونت يرسل POST إلى سيرفر الإدارة
↓
السيرفر يتحقق من البيانات ويرسل التوكن
↓
الفرونت يحفظ التوكن وبيانات المستخدم
↓
الفرونت يعرض الواجهة الرئيسية
```

### 2. الطلبات اللاحقة
```
الفرونت يأخذ التوكن من localStorage
↓
يضيفه إلى هيدر Authorization
↓
يرسل الطلب إلى السيرفر
↓
السيرفر يتحقق من التوكن
↓
إذا صحيح → يعالج الطلب
إذا خاطئ → يرسل 401 Unauthorized
```

### 3. تسجيل الخروج
```
المستخدم يضغط على "تسجيل الخروج"
↓
الفرونت يحذف التوكن وبيانات المستخدم من localStorage
↓
الفرونت يعيد توجيه المستخدم إلى صفحة تسجيل الدخول
```

## ربط المهام برقم المستخدم

### عند فتح مهمة من نظام الإدارة

1. المدير ينشئ مهمة بنظام الإدارة
2. المحرر يفتح المهمة ويضغط على "افتح نظام الأخبار"
3. الفرونت يفتح رابط نظام الأخبار مع رقم المهمة:
   ```
   https://news-system.onrender.com/editorial?task_id=45
   ```

4. نظام الأخبار يأخذ رقم المهمة من الرابط
5. كل عملية يعملها المحرر تُحفظ مع:
   - رقم المهمة (`task_id`)
   - رقم المستخدم (`user_id` من التوكن)

### عند فتح نظام الأخبار مباشرة

1. المحرر يفتح نظام الأخبار مباشرة (بدون مهمة)
2. لا يوجد `task_id` في الرابط
3. العمليات تُحفظ برقم المستخدم فقط
4. لا تكون مربوطة بمهمة معينة

## الأمان

### التوكن
- يُحفظ في `localStorage` (يمكن الوصول إليه من JavaScript)
- يُرسل مع كل طلب في هيدر `Authorization`
- ينتهي بعد 24 ساعة (قابل للتعديل)

### كلمة المرور
- لا تُحفظ في الفرونت
- تُرسل مرة واحدة فقط عند تسجيل الدخول
- تُشفر بـ bcryptjs على السيرفر

### الصلاحيات
- تُجلب من السيرفر بعد تسجيل الدخول
- تُستخدم للتحكم في ما يراه المستخدم بالواجهة
- تُتحقق أيضاً على السيرفر (لا تعتمد على الفرونت)

## استكشاف الأخطاء

### "فشل تسجيل الدخول"
- تحقق من البريد الإلكتروني وكلمة المرور
- تأكد من أن السيرفر يعمل
- تحقق من متغيرات البيئة

### "فشل جلب بيانات المستخدم"
- تأكد من أن التوكن صحيح
- تأكد من أن السيرفر يعمل
- تحقق من الصلاحيات

### "Access denied. No token provided"
- تأكد من أن التوكن محفوظ في localStorage
- تأكد من أن الهيدر يُرسل بشكل صحيح
- جرب تسجيل الدخول مرة أخرى

## الخطوات التالية

1. **ربط المهام**: عند فتح مهمة من نظام الإدارة، يجب تمرير رقم المهمة إلى نظام الأخبار
2. **حفظ رقم المستخدم**: كل عملية بنظام الأخبار يجب أن تحفظ رقم المستخدم
3. **مؤشرات الأداء**: قراءة من جداول نظام الأخبار وحساب إحصائيات لكل موظف
4. **الإشعارات**: إرسال إشعارات للمدير عند نشر أخبار جديدة
