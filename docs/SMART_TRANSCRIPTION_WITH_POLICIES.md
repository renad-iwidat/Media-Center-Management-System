# Smart Transcription - مع سياسات التحرير

## الميزات الجديدة

### 1. رفع الملفات مباشرة
يمكنك الآن رفع ملفات صوتية أو فيديو مباشرة من Smart Transcription:

```
┌─────────────────────────────────────────┐
│  اختر ملفاً                             │
├─────────────────────────────────────────┤
│  [البحث]                                │
│  [الكل] [صوت] [فيديو]                  │
│  ─────────────────────────────────────  │
│  [الملف 1]                              │
│  [الملف 2]                              │
│  [الملف 3]                              │
│  ─────────────────────────────────────  │
│  [رفع ملف جديد] ← جديد!                │
└─────────────────────────────────────────┘
```

### 2. سياسات التحرير المتكاملة
تظهر سياسات التحرير في الجانب الأيمن:

```
┌─────────────────────────────────────────┐
│  سياسة التحرير                          │
├─────────────────────────────────────────┤
│  [اختر سياسة...]                        │
│  ─────────────────────────────────────  │
│  • سياسة الأخبار الرئيسية              │
│  • سياسة الأخبار الرياضية              │
│  • سياسة الأخبار الاقتصادية            │
│  ─────────────────────────────────────  │
│  [+ إضافة سياسة جديدة]                 │
└─────────────────────────────────────────┘
```

### 3. معلومات إضافية
يمكنك إضافة معلومات إضافية تُستخدم في المعالجة:

```
┌─────────────────────────────────────────┐
│  معلومات إضافية                        │
├─────────────────────────────────────────┤
│  [أرقام، إحصائيات، أو معلومات محددة]  │
│                                         │
│  مثال:                                  │
│  - عدد الضحايا: 50                      │
│  - المدينة: دمشق                       │
│  - التاريخ: 15/5/2024                   │
└─────────────────────────────────────────┘
```

## خطوات الاستخدام

### الخطوة 1: اختر سياسة التحرير
1. انقر على قائمة "سياسات التحرير"
2. اختر السياسة المناسبة من القائمة
3. ستظهر السياسة المختارة أسفل القائمة

### الخطوة 2: أضف معلومات إضافية (اختياري)
1. اكتب أي معلومات إضافية في حقل "معلومات إضافية"
2. مثل: أرقام، إحصائيات، أو سياق محدد

### الخطوة 3: اختر ملفاً أو رفع ملف جديد
**الخيار أ: اختر ملف موجود**
1. ابحث عن الملف في القائمة
2. استخدم الفلاتر (الكل / صوت / فيديو)
3. انقر على الملف لاختياره

**الخيار ب: رفع ملف جديد**
1. انقر على زر "رفع ملف جديد"
2. اختر ملف صوتي أو فيديو
3. سيتم رفعه ومعالجته مباشرة

### الخطوة 4: اختر المخرجات المطلوبة
1. حدد المخرجات التي تريدها:
   - ✓ ملخص تنفيذي
   - ✓ خبر صحفي
   - ✓ تقرير صحفي
   - ✓ منشورات سوشيال ميديا
   - ✓ مقاطع فيديو
   - ✓ تنبيهات سياسة التحرير

2. للمخرجات المتعددة (سوشيال ميديا، مقاطع فيديو)، حدد العدد

### الخطوة 5: بدء المعالجة
1. انقر على "بدء التفريغ"
2. سيتم معالجة الملف وتوليد المخرجات
3. ستظهر النتائج تلقائياً

### الخطوة 6: عرض والمخرجات
1. انقر على أي مخرج لمعاينته
2. استخدم زر "تحميل الملف الموحد" لتحميل جميع المخرجات

## API Integration

### المعاملات المرسلة

عند بدء المعالجة، يتم إرسال البيانات التالية:

```typescript
{
  fileUrl: "https://...",           // رابط الملف
  fileType: "audio" | "video",      // نوع الملف
  language: "ar",                   // اللغة
  outputs: [                         // المخرجات المطلوبة
    { type: "executive_summary", enabled: true },
    { type: "news_article", enabled: true },
    // ...
  ],
  editorialPolicy: "نص السياسة",    // سياسة التحرير المختارة
  customInfo: "معلومات إضافية"      // المعلومات الإضافية
}
```

### الاستجابة

```typescript
{
  success: true,
  data: {
    transcript: "النص المفرّغ...",
    outputs: [
      {
        type: "executive_summary",
        content: "الملخص التنفيذي...",
        metadata: { ... }
      },
      // ...
    ],
    metadata: {
      generatedAt: "2024-05-15T10:30:00Z",
      language: "ar",
      editorialPolicy: true,
      customInfo: true,
      outputsGenerated: 6,
      outputsFailed: 0
    }
  }
}
```

## الحالات الخاصة

### 1. عند رفع ملف جديد
- يتم إضافة الملف إلى القائمة مؤقتاً
- يتم معالجته مباشرة
- يظهر في القائمة بعد الانتهاء

### 2. عند اختيار ملف موجود
- يتم تحديده بلون مختلف
- يمكن معاينته (صوت أو فيديو)
- يتم معالجته عند النقر على "بدء التفريغ"

### 3. عند عدم اختيار سياسة
- يتم إرسال `editorialPolicy: ""`
- يتم معالجة الملف بدون سياسة محددة
- تنبيهات السياسة ستكون عامة

### 4. عند إضافة معلومات إضافية
- يتم إرسالها مع الطلب
- تُستخدم في توليد المخرجات
- تساعد في تحسين دقة النتائج

## الأخطاء الشائعة

### خطأ: "لا توجد ملفات مرفوعة"
- تأكد من أنك رفعت ملفات صوتية أو فيديو
- استخدم قسم "Upload Files" لرفع الملفات

### خطأ: "فشل التفريغ"
- تأكد من أن الملف صحيح
- تأكد من أن الملف لا يتجاوز 60 دقيقة
- جرب ملف آخر

### خطأ: "فشل توليد المخرجات"
- تأكد من أن التفريغ نجح
- جرب اختيار مخرجات أقل
- تحقق من سياسة التحرير

## نصائح مهمة

1. **اختر السياسة أولاً**: اختر سياسة التحرير قبل رفع الملف
2. **أضف معلومات إضافية**: كلما أضفت معلومات أكثر، كانت النتائج أفضل
3. **اختر المخرجات المناسبة**: لا تختر جميع المخرجات إذا لم تحتجها
4. **معاينة الملفات**: استمع للملف الصوتي قبل المعالجة
5. **احفظ النتائج**: استخدم "تحميل الملف الموحد" لحفظ جميع المخرجات
