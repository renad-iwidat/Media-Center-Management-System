# 🌐 نظام النشر التلقائي على المواقع الخارجية

## نظرة عامة

نظام النشر التلقائي ينشر الأخبار المعتمدة من مركز الإعلام على المواقع الخارجية (مثل موقع هنا غزة) بشكل آلي أو يدوي حسب نوع الخبر.

---

```
┌─────────────────────────────────────────────────────────────────┐
│                    الـ Scheduler (كل 10-15 دقيقة)                │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │

│      │   محلي، دولي، سياسي                          │            │
│      │   → يروح لاستديو التحرير (المحرر يقرر)      │            │

│                                                                  │
│  المرحلة 3: نشر الأخبار الأوتوماتيكية العالقة                   │
│  ─────────────────────────────────────────                       │
│  • أي خبر أوتوماتيكي مكتمل بقي بحالة pending → ينشر تلقائياً   │
│                                                                  │
│  المرحلة 4: النشر التلقائي على المواقع الخارجية ⭐               │
│  ─────────────────────────────────────────                       │
│  • يفحص الأخبار المنشورة محلياً (published_items)               │
│  • يجلب الأهداف المفعّلة (auto_publish_targets)                 │
│  • ينشر فقط الأخبار الأوتوماتيكية (flow = automated)           │
│  • يرسل كل خبر عبر API الموقع الخارجي                          │
│  • يسجل النتيجة بـ auto_publish_log                             │
│  • يعيد محاولة الفاشل (حد أقصى 3 محاولات)                      │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

## 📊 الأرقام والإعدادات

| الإعداد | القيمة الافتراضية | الوصف |
|---------|-------------------|-------|
| `scheduler_interval_minutes` | 10 دقائق | الفاصل بين كل دورة سحب ومعالجة |
| `articles_per_source` | 20 | عدد المقالات المسحوبة من الـ API بكل دورة |
| `auto_publish_enabled` | false | Master switch — لازم يكون true عشان يشتغل |
| حد النشر بكل دورة | 20 خبر | أقصى عدد أخبار تنشر بكل دورة لكل هدف |
| تأخير بين كل طلب | 500ms | لتجنب rate limiting على الموقع الخارجي |
| حد إعادة المحاولة | 3 محاولات | بعدها يتوقف عن المحاولة |

## 🎯 أنواع النشر

### 1. النشر التلقائي (Automated)
- **التصنيفات:** اقتصاد، رياضة، صحة، تكنولوجيا، ثقافة، بيئة، غذاء
- **الآلية:** ينشر تلقائياً مع كل دورة scheduler بدون تدخل بشري
- **الشرط:** الخبر لازم يكون:
  - منشور محلياً (في `published_items`)
  - تصنيفه `flow = 'automated'`
  - لم يُنشر مسبقاً على نفس الهدف

### 2. النشر اليدوي (Editorial)
- **التصنيفات:** محلي، دولي، سياسي
- **الآلية:** المحرر يشتغل على الخبر باستديو التحرير → يكبس "موافقة ونشر" → يطلعلو dialog يختار الموقع الخارجي → ينشر مباشرة
- **بعد النشر:**
  - الخبر ينتقل للأرشيف المنشور
  - ينشر على الموقع/المواقع الخارجية اللي اختارها المحرر
  - رابط الخبر المنشور يظهر بالأرشيف لسهولة المتابعة

## 🔌 API Endpoints

### إدارة النشر التلقائي

| Method | Endpoint | الوصف |
|--------|----------|-------|
| GET | `/api/auto-publish/status` | حالة النظام + إحصائيات لكل هدف |
| POST | `/api/auto-publish/toggle` | تفعيل/إيقاف النشر التلقائي (master) |
| GET | `/api/auto-publish/targets` | جميع أهداف النشر |
| GET | `/api/auto-publish/targets/:id` | هدف واحد |
| POST | `/api/auto-publish/targets` | إنشاء هدف جديد |
| PATCH | `/api/auto-publish/targets/:id` | تحديث هدف |
| DELETE | `/api/auto-publish/targets/:id` | حذف هدف |
| POST | `/api/auto-publish/targets/:id/toggle` | تفعيل/إيقاف هدف معين |

### تشغيل النشر

| Method | Endpoint | الوصف |
|--------|----------|-------|
| POST | `/api/auto-publish/run` | تشغيل يدوي فوري (كل الأخبار الأوتوماتيكية) |
| POST | `/api/auto-publish/publish-one` | نشر خبر واحد يدوياً (المحرر) |
| POST | `/api/auto-publish/retry` | إعادة محاولة الأخبار الفاشلة |
| GET | `/api/auto-publish/log` | سجل النشر |

### أمثلة

```bash
# تفعيل النشر التلقائي
curl -X POST /api/auto-publish/toggle \
  -H "Authorization: Bearer TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"enabled": true}'

# تفعيل هدف هنا غزة
curl -X POST /api/auto-publish/targets/1/toggle \
  -H "Authorization: Bearer TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"enabled": true}'

# نشر خبر يدوياً (المحرر)
curl -X POST /api/auto-publish/publish-one \
  -H "Authorization: Bearer TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"raw_data_id": 123, "target_id": 1}'

# تشغيل يدوي فوري
curl -X POST /api/auto-publish/run \
  -H "Authorization: Bearer TOKEN"
```

## ⚠️ ملاحظات مهمة

1. **السحب كل ساعتين فقط** — لتجنب إدخال أخبار قديمة وتصنيفها كجديدة
2. **الأخبار تنشر كـ draft** على موقع هنا غزة — يمكن مراجعتها من لوحة تحكم الموقع
3. **رابط الخبر المنشور** يُحفظ تلقائياً ويظهر بالأرشيف لسهولة المتابعة
4. **لا يتم نشر نفس الخبر مرتين** — النظام يتتبع ما تم نشره بـ `auto_publish_log`
5. **Rate Limiting** — تأخير 500ms بين كل طلب لتجنب حظر الـ API
6. **إعادة المحاولة** — الأخبار الفاشلة تُعاد محاولتها (حد أقصى 3 مرات)
7. **Master Switch** — إذا أوقفت النشر التلقائي، لا ينشر شي حتى لو الأهداف مفعّلة

## 🔗 روابط الأخبار المنشورة (الأرشيف)

بعد نشر أي خبر على موقع خارجي (سواء تلقائي أو يدوي):
- يُحفظ رابط الخبر (`external_url`) و ID الخبر (`external_id`) في `auto_publish_log`
- يمكن جلب الروابط عبر:
  ```
  GET /api/auto-publish/external-links/:rawDataId
  POST /api/auto-publish/external-links/batch { "raw_data_ids": [1,2,3] }
  ```
- الروابط تظهر بالأرشيف المنشور بجانب كل خبر
