# تحديثات نظام التفريغ الذكي

## التحديث الأخير: إدارة سياسات التحرير

### ما الجديد؟

تم إضافة نظام متكامل لإدارة سياسات التحرير مباشرة من واجهة التفريغ الذكي.

### المميزات المضافة

#### 1. مكون EditorialPolicyManager
- **الموقع**: `frontend/src/components/ai/EditorialPolicyManager.tsx`
- **الوظيفة**: إدارة كاملة لسياسات التحرير

#### 2. الميزات الرئيسية
- ✅ عرض السياسات المحفوظة في قائمة منسدلة
- ✅ إضافة سياسات جديدة
- ✅ تحرير السياسات الموجودة
- ✅ حذف السياسات
- ✅ اختيار السياسة المطلوبة
- ✅ عرض السياسة المختارة

### كيفية الاستخدام

#### إضافة سياسة جديدة
```
1. انتقل إلى "التفريغ الذكي"
2. اضغط على قائمة السياسات
3. اختر "إضافة سياسة جديدة"
4. أدخل اسم السياسة والمحتوى
5. اضغط "إضافة"
```

#### اختيار سياسة موجودة
```
1. اضغط على قائمة السياسات
2. اختر السياسة من القائمة
3. سيتم تطبيقها تلقائياً
```

#### تحرير سياسة
```
1. اضغط على قائمة السياسات
2. اضغط على أيقونة التحرير بجانب السياسة
3. عدّل البيانات
4. اضغط "تحديث"
```

#### حذف سياسة
```
1. اضغط على قائمة السياسات
2. اضغط على أيقونة الحذف بجانب السياسة
3. أكّد الحذف
```

### التكامل مع الـ API

يستخدم المكون الـ API endpoints الموجودة:
- `GET /api/news/editorial-policies` - جلب السياسات
- `POST /api/news/editorial-policies` - إضافة سياسة
- `PUT /api/news/editorial-policies/:name` - تحديث سياسة
- `DELETE /api/news/editorial-policies/:name` - حذف سياسة

```

- ممنوع الكلمات النابية
- ممنوع التحيز السياسي

- يجب نسب التصريحات
```

#### مثال 2: سياسة الأخبار الاقتصادية
```
اسم: سياسة الأخبار الاقتصادية

```
