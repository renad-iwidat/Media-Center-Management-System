# 📰 نظام إدارة المركز الإعلامي — توثيق شامل

## نظرة عامة

نظام إدارة مركز إعلامي متكامل مصمم لغرف الأخبار العربية. يُؤتمت دورة حياة الأخبار بالكامل: من سحب الأخبار من مصادر خارجية، مروراً بالتصنيف الذكي بالذكاء الاصطناعي، والمراجعة التحريرية، وصولاً للنشر — بالإضافة لمجموعة أدوات ذكاء اصطناعي متقدمة للصحفيين والمحررين.

## 🎯 الميزات الرئيسية (Features)

### 1. 📰 نظام إدارة الأخبار (News Management)

#### نظرة عامة (Overview Dashboard)
- إحصائيات شاملة: عدد الأخبار المسحوبة، المعلقة، المنشورة، المرفوضة
- إحصائيات يومية لآخر 30 يوم
- آخر الأخبار المعلقة والمنشورة
- فلترة حسب الوحدة الإعلامية

#### مصادر المحتوى (Sources)
- إدارة مصادر الأخبار الخارجية
- مزامنة تلقائية مع NewsDesk API
- تفعيل/تعطيل المصادر
- تتبع آخر عملية سحب لكل مصدر

#### أخبار غير مكتملة (Incomplete)
- عرض الأخبار التي تحتاج إكمال (محتوى أقل من 100 حرف)
- إمكانية إكمال المحتوى يدوياً
- إعادة إرسال للمعالجة بعد الإكمال

#### قسم التحرير (Editorial Queue)
- طابور المراجعة التحريرية
- موافقة/رفض الأخبار
- تعديل المحتوى قبل النشر
- فلترة حسب الحالة (معلق، مكتمل، مرفوض)

#### السياسات التحريرية (Editorial Policies)
- تعريف سياسات تحرير مخصصة لكل قناة
- قوالب prompt مع متغيرات قابلة للحقن
- تطبيق السياسات تلقائياً عبر AI
- فحص المحتوى ضد السياسات قبل النشر

#### قسم النشر (Published)
- عرض الأخبار المنشورة
- إحصائيات النشر حسب الوحدة الإعلامية
- تصدير وأرشفة

### 2. 🤖 أدوات الذكاء الاصطناعي (AI Hub)

#### التفريغ الذكي (Smart Transcription) ⭐
أقوى أداة في النظام — تستقبل ملف صوت أو فيديو وتُنتج 6 مخرجات تحريرية:

| المخرج | الوصف |
|--------|-------|
| الملخص التنفيذي | 4-6 أسطر بأهم ما ورد |
| الخبر الصحفي | خبر مكتمل بنية الهرم المقلوب |
| التقرير الصحفي | تقرير معمّق باحترافية |
| منشورات سوشيال ميديا | منشورات مع تصريحات منسوبة |
| مقاطع فيديو | مقاطع مهمة مع تايم كود |
| تنبيهات السياسة | فحص مخالفات سياسة التحرير |

**آلية العمل:**
1. رفع ملف صوت/فيديو (1-60 دقيقة)
2. تقسيم الصوت لأجزاء (chunks) ومعالجتها بالتوازي
3. تفريغ صوتي عبر OpenAI Whisper
4. تصحيح النص المفرّغ
5. توليد المخرجات عبر AI Model (مع fallback لـ OpenAI)

#### المختبر الصوتي (Audio Processing)
- تحويل صوت لنص (STT) مع timestamps
- تحويل نص لصوت (TTS)
- معالجة متوازية للملفات الكبيرة
- دعم استخراج الصوت من الفيديو

#### مساعد AI ذكي (Chat Interface)
- دردشة تفاعلية مع مساعد ذكي
- متخصص بالمهام الإعلامية والصحفية
- يفهم السياق العربي

#### وحدة التفكير (Idea Generation)
- توليد عناوين إبداعية
- اقتراح أسئلة مقابلات
- أفكار لتغطيات صحفية
- عصف ذهني للمحتوى

#### التحرير الصحفي (Text Editing)
- إعادة صياغة النصوص
- تلخيص المحتوى
- تدقيق لغوي
- تحسين الأسلوب الصحفي

#### التواصل الاجتماعي (Social Media)
- توليد منشورات لمنصات مختلفة
- اقتراح هاشتاجات
- تكييف المحتوى لكل منصة

#### غرفة الأخبار (NewsRoom)
- إنشاء نشرات إخبارية (صباحية/مسائية)
- موجزات أخبار
- حفظ وأرشفة النشرات
- تصدير كمستندات

### 3. 🔄 نظام الفلو الآلي (Automated News Flow)

```
┌──────────────┐    ┌──────────────┐    ┌─────────────────┐    ┌─────────────────┐
│  NewsDesk    │───►│  raw_data    │───►│ editorial_queue │───►│ published_items │
│  API         │    │  (تخزين)     │    │  (طابور)        │    │  (منشور)        │
└──────────────┘    └──────────────┘    └─────────────────┘    └─────────────────┘
     سحب              معالجة              تحرير                  نشر
```

#### المرحلة 1: السحب (Fetching)
- **Scheduler** يعمل كل 15 دقيقة (قابل للتعديل)
- يتصل بـ NewsDesk API ويجلب المقالات الجديدة
- فحص تكرار (deduplication) بالـ ID والـ URL
- ربط المصدر والتصنيف والمنطقة الجغرافية
- حفظ بجدول `raw_data` بستيتوس `fetched`

#### المرحلة 2: المعالجة والتوجيه (Flow Routing)
- **AI Classifier** يصنف الأخبار بدون تصنيف
- فحص اكتمال المحتوى (≥ 100 حرف)
- تحديد نوع الفلو حسب التصنيف:

| الفلو | التصنيفات |
|-------|-----------|
| **أوتوماتيكي** (نشر مباشر) | اقتصاد، رياضة، صحة، تكنولوجيا، ثقافة، بيئة، غذاء |
| **تحريري** (يحتاج موافقة) | سياسة، محلي، دولي، مجتمع، أمن |

- التوزيع على كل الوحدات الإعلامية النشطة

#### المرحلة 3: طابور التحرير
| الحالة | المعنى |
|--------|--------|
| `incomplete` | محتوى ناقص — ينتظر الإكمال |
| `pending` | مكتمل تحريري — ينتظر موافقة المحرر |
| `approved` | تمت الموافقة — جاهز للنشر |
| `rejected` | مرفوض |

#### المرحلة 4: النشر
- **أوتوماتيكي:** FlowRouter ينشر مباشرة بدون تدخل
- **يدوي:** المحرر يوافق من قسم التحرير
- **نشر خارجي:** Auto-Publish لمواقع WordPress/CMS خارجية

---

### 4. 👥 نظام المستخدمين والصلاحيات

- تسجيل دخول بـ JWT (صالح 24 ساعة)
- أدوار مختلفة (Admin, Editor, Viewer)
- إدارة المستخدمين (إنشاء، تعديل، تعطيل)
- تشفير كلمات السر بـ bcrypt
- حماية الـ API بـ middleware

---

### 5. 🏢 الوحدات الإعلامية (Media Units)

- دعم وحدات إعلامية متعددة (Multi-tenant)
- كل خبر يُوزع على كل الوحدات النشطة
- فلترة المحتوى حسب الوحدة
- أهداف نشر خارجية لكل وحدة
- إحصائيات منفصلة لكل وحدة

---

### 6. 📊 النشر التلقائي الخارجي (Auto-Publish)

- نشر الأخبار المعتمدة على مواقع خارجية
- ربط مع WordPress REST API
- ربط التصنيفات المحلية بتصنيفات الموقع الخارجي
- تتبع حالة النشر (نجح/فشل/تم تخطيه)
- أهداف نشر متعددة لكل وحدة إعلامية

---

### 7. 📋 النشرات والموجزات (Bulletins)

- إنشاء نشرات إخبارية (صباحية/مسائية)
- موجزات أخبار مختصرة
- حفظ كمسودة أو نشر
- تعديل المحتوى المولّد
- أرشفة النشرات القديمة

## 🖥️ واجهة المستخدم (UI Flow)

### التنقل الرئيسي
التطبيق مقسم لقسمين رئيسيين بالـ Sidebar:

**إدارة الأخبار:**
1. نظرة عامة → إحصائيات ولوحة تحكم
2. مصادر المحتوى → إدارة المصادر
3. أخبار غير مكتملة → إكمال المحتوى الناقص
4. قسم التحرير → مراجعة وموافقة
5. السياسات التحريرية → إدارة القواعد
6. قسم النشر → الأخبار المنشورة

**أدوات الذكاء الاصطناعي:**
1. التفريغ الذكي → تفريغ صوت/فيديو + مخرجات
2. وحدة التفكير → توليد أفكار
3. التحرير الصحفي → إعادة صياغة
4. التواصل الاجتماعي → منشورات
5. المختبر الصوتي → STT/TTS
6. غرفة الأخبار → نشرات
7. مساعد AI ذكي → دردشة

### تجربة المستخدم
- تصميم RTL كامل (عربي)
- واجهة مبسطة وواضحة
- Sidebar قابل للطي
- اختيار الوحدة الإعلامية من الأعلى
- حركات وانتقالات سلسة (Framer Motion)
- تصميم متجاوب (Responsive)

## 📝 ملاحظات تقنية

- النظام يستخدم **AI Model محلي** (vLLM على سيرفر خاص) كخيار أول، مع **fallback لـ OpenAI** إذا فشل
- التفريغ الصوتي يستخدم **معالجة متوازية** (Parallel STT) لتسريع الأداء — يقسم الصوت لأجزاء ويعالجها بالتوازي
- النظام يدعم **overlap** بين الأجزاء الصوتية لتجنب قطع الكلمات
- **Rate Limiter** يحمي من الاستخدام المفرط لـ API
- **AI Usage Logger** يسجل كل استخدام للذكاء الاصطناعي للتحليل
- الفرونت اند يدعم **Runtime Environment Variables** من Docker (window.ENV)
