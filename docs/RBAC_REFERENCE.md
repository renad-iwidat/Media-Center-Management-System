## 5. تحليل المشاكل الموجودة

### 🔴 مشكلة 1: كل الأدوار تمتلك نفس الصلاحيات الأساسية

**المشكلة:** المونتير والجرافيك والفني الصوتي وغيرهم — كلهم يملكون `orders.create`, `orders.delete`, `tasks.assign` وهي صلاحيات لا معنى لها بالنسبة لهم.

**الأثر:** أي موظف يمكنه إنشاء أوردرات وحذفها وتعيين مهام لآخرين.

**الحل المقترح:**
```
أدوار الإنتاج (مونتير، جرافيك، فني صوت، مخرج، مصور، Makeup):
  ✅ orders.view      (يشوف الأوردرات المخصصة له فقط)
  ✅ tasks.view       (يشوف مهامه فقط)
  ✅ content.create   (يرفع محتوى)
  ✅ content.view     (يشوف المحتوى)
  ❌ orders.create    (ما يحتاجها)
  ❌ orders.delete    (ما يحتاجها)
  ❌ tasks.assign     (ما يحتاجها)
  ❌ tasks.delete     (ما يحتاجها)
```

### 8.2 فحص الصلاحية في الـ Frontend

```typescript
// دالة مساعدة للفحص

}
```

```sql
SELECT DISTINCT p.name
FROM users u
-- صلاحيات الدور الأساسي
LEFT JOIN role_permissions rp1 ON rp1.role_id = u.role_id
LEFT JOIN permissions p1 ON p1.id = rp1.permission_id
-- صلاحيات الأدوار الإضافية
LEFT JOIN user_roles ur ON ur.user_id = u.id
LEFT JOIN role_permissions rp2 ON rp2.role_id = ur.role_id
LEFT JOIN permissions p2 ON p2.id = rp2.permission_id
-- الصلاحيات اليدوية
LEFT JOIN user_permissions up ON up.user_id = u.id
LEFT JOIN permissions p3 ON p3.id = up.permission_id
WHERE u.id = :userId
AND (p1.name IS NOT NULL OR p2.name IS NOT NULL OR p3.name IS NOT NULL)
```
