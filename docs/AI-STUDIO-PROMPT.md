# برومبت لبناء الفرونت — نظام إدارة مركز الإعلام الداخلي

أنا عندي نظام باك إند جاهز ومنشور لإدارة مركز إعلام داخلي. بدي تبنيلي واجهة أمامية احترافية وذكية تغطي كل الفيتشرات.

## عن النظام

نظام متكامل لإدارة مركز إعلام — بيغطي كل مراحل العمل من الفكرة حتى الأرشفة. فيه إدارة أوردرات ومهام، تصوير ميداني، إنتاج محتوى، أرشيف ذكي قابل لإعادة الاستخدام، مؤشرات أداء شاملة، إشعارات لحظية، ونظام مصادقة وصلاحيات كامل.

## التفاصيل التقنية

- الباك إند: Node.js + Express + TypeScript + PostgreSQL
- السيرفر منشور على: `https://media-center-management-system.onrender.com`
- المصادقة: JWT — كل طلب لازم يكون معه توكن بالهيدر
- الإشعارات اللحظية: Socket.IO على نفس الرابط
- كل التفاصيل بالملف المرفق (FRONTEND-API-GUIDE.md)

## المطلوب

ابنيلي واجهة أمامية احترافية بتغطي:

1. **صفحة تسجيل الدخول** — بالإيميل وكلمة السر. بعد الدخول يتحفظ التوكن ويتفتح اتصال ويب سوكت للإشعارات.

2. **لوحة تحكم رئيسية** — تعرض ملخص الأوردرات والمهام والمحتوى ومؤشرات الأداء وأفضل الموظفين. مع فلترة بالفترة الزمنية ومقارنات شهرية. هاي فقط للإدارة.

3. **إدارة الأوردرات** — إنشاء وتعديل وحذف وتغيير حالات وفلترة. مع عرض التقدم والمهام المرتبطة والتاريخ.

4. **إدارة المهام** — إنشاء وتعيين وتغيير حالات. مع تعليقات ومرفقات وعلاقات بين المهام. وعرض المهام المتأخرة.

5. **إدارة التصوير** — إنشاء تصوير مرتبط بأوردر ومهمة. مع عرض المحتوى المنتج من كل تصوير.

6. **المحتوى والأرشيف** — رفع محتوى، إنشاء من تصوير (فردي ودفعة)، بحث وفلترة موحدة، وسوم، إعادة استخدام محتوى مؤرشف بمهام جديدة. الأرشيف هو كل المحتوى النهائي — بيتأرشف تلقائي.

7. **الإشعارات** — أيقونة بفقاعة عدد غير المقروءة. قائمة إشعارات. إشعارات لحظية عبر ويب سوكت.

8. **إدارة المستخدمين والصلاحيات** — إضافة وتعديل مستخدمين، تعيين أدوار متعددة، عرض صلاحيات. هاي فقط للإدارة.

9. **البرامج والحلقات** — إدارة البرامج والحلقات والضيوف وفريق البرنامج. الحلقات بتعرض حالتها من الأوردر المرتبط.

10. **الأقسام والفرق** — إدارة الأقسام والفرق وأعضائها.

## ملاحظات مهمة

- الواجهة لازم تكون بالعربية (اتجاه من اليمين لليسار)
- الواجهة لازم تعرض/تخفي الأقسام حسب صلاحيات المستخدم (تستخدم نقطة وصول "بياناتي" بعد تسجيل الدخول)
- النظام مرتبط بنظام أخبار وذكاء اصطناعي منفصل — المهام المتعلقة بالأخبار بتفتح نظام الأخبار بنافذة أو تبويب جديد
- الفلو الأساسي: أوردر ← مهام ← تصوير ← محتوى ← أرشيف — كلشي مترابط
- كل التفاصيل التقنية (نقاط الوصول، شكل البيانات، الحالات، الصلاحيات) بالملف المرفق
