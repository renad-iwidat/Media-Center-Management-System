# بناء واجهة أمامية كاملة وشغالة — نظام إدارة مركز الإعلام الداخلي

## المطلوب

ابنيلي موقع ويب كامل وشغال مربوط بسيرفر جاهز. مش بس تصميم — بدي كل شاشة تسحب بيانات حقيقية من السيرفر وتعرضها وتتفاعل معها. كل زر يشتغل، كل رابط يوصل، كل نموذج يبعث بيانات ويستقبل رد.

الملف المرفق (FRONTEND-API-GUIDE.md) فيه كل نقاط الوصول بالتفصيل — المسارات، شكل البيانات المطلوبة والمرجعة، الحالات، الصلاحيات، وكود الإشعارات اللحظية. استخدمه كمرجع أساسي لكل شي.

## معلومات السيرفر

- **رابط السيرفر:** `https://media-center-management-system.onrender.com`
- **صيغة البيانات:** JSON
- **المصادقة:** كل طلب لازم يكون معه توكن بالهيدر: `Authorization: Bearer TOKEN`
- **الإشعارات اللحظية:** Socket.IO على نفس الرابط
- **حساب تجريبي:** `gmortaja@najah.edu` / `admin123`

## عن النظام

نظام متكامل لإدارة مركز إعلام. بيغطي كل مراحل العمل: من إنشاء طلب عمل (أوردر) لتعيين مهام لتصوير ميداني لإنتاج محتوى لأرشفة ذكية. مع مؤشرات أداء شاملة وإشعارات لحظية ونظام صلاحيات متقدم.

الفلو الأساسي:
```
تسجيل دخول → إنشاء أوردر → تعيين مهام → تنفيذ (تصوير/تحرير/مونتاج)
→ رفع محتوى → أرشفة تلقائية → مؤشرات أداء → إشعارات لحظية
```

## الشاشات المطلوبة بالتفصيل

### 1. تسجيل الدخول
- نموذج بالإيميل وكلمة السر
- بعد الدخول: حفظ التوكن + فتح اتصال ويب سوكت للإشعارات
- استدعاء نقطة "بياناتي" (`GET /api/auth/me`) لجلب صلاحيات المستخدم
- توجيه المستخدم حسب صلاحياته (الإدارة تشوف لوحة التحكم، الموظف يشوف مهامه)

### 2. لوحة التحكم الرئيسية (للإدارة فقط — صلاحية kpi.view)
- **بطاقات ملخص:** إجمالي الأوردرات (مكتملة/جارية/معلقة/متأخرة)، إجمالي المهام، إجمالي المحتوى، عدد الموظفين
- **نسب الإنجاز:** بأشكال بيانية (دائري أو شريطي)
- **متوسط وقت الإنجاز ونسبة الالتزام بالمواعيد**
- **أفضل 5 موظفين** بجدول
- **إحصائيات إعادة الاستخدام** (إجمالي + أكثر المحتويات استخداماً)
- **مقارنات شهرية** (`GET /api/kpi/trends`) بشكل بياني
- **فلترة بالفترة الزمنية** (من تاريخ — لتاريخ)
- كل البيانات من: `GET /api/kpi/dashboard?from=...&to=...`

### 3. الأوردرات (طلبات العمل)
- **قائمة الأوردرات** بجدول مع فلترة (حسب القسم، الحالة، البرنامج) وصفحات
- **إنشاء أوردر جديد** بنموذج (عنوان، وصف، قسم، أولوية، وحدة إعلامية، برنامج، موعد نهائي)
- **تفاصيل الأوردر** — فيها: المهام المرتبطة مع حالاتها، نسبة التقدم (شريط)، تاريخ تغييرات الحالة، المحتوى المنتج
- **تغيير الحالة** بأزرار واضحة حسب التسلسل المسموح: `Created → Pending → In Progress → Review → Done`
- **زر إلغاء** وزر أرشفة
- **فحص إمكانية الإغلاق** (`GET /api/orders/:id/can-close`) — يعرض رسالة إذا ما بينقفل (مهام ناقصة أو ما في محتوى)

### 4. المهام
- **قائمة المهام** بجدول مع فلترة (حسب الأوردر، الموظف، الحالة، المتأخرة)
- **إنشاء مهمة** مرتبطة بأوردر — مع تعيين لموظف وموعد نهائي
- **تفاصيل المهمة** — فيها: التعليقات (إضافة وعرض)، المرفقات (رفع وعرض)، العلاقات والتبعيات، تاريخ التعيينات، تاريخ تغييرات الحالة
- **تغيير الحالة** بأزرار: `Pending → In Progress → Review → Done`
- **تعيين جماعي** وتغيير حالة جماعي (اختيار عدة مهام + تنفيذ)
- **المهام المتأخرة** بقسم خاص أو فلتر

### 5. التصوير
- **قائمة التصويرات** — استخدم النقطة المخصبة (`GET /api/shootings/enriched`) اللي بترجع اسم الأوردر وحالة المهمة وعدد المحتوى
- **إنشاء تصوير** مرتبط بأوردر ومهمة — مع الموقع والموعد والمعدات والطاقم ونوع المصدر (داخلي/خارجي)
- **تفاصيل التصوير** (`GET /api/shootings/:id/full`) — فيها كل المحتوى المنتج من هاد التصوير
- **زر "إنشاء محتوى من التصوير"** — يفتح نموذج لإنشاء محتوى (فردي أو دفعة)

### 6. المحتوى والأرشيف
- **صفحة واحدة موحدة** للمحتوى والأرشيف — الفرق بس بالفلتر (`archived=true`)
- **بحث وفلترة** بالكلمة المفتاحية، النوع (فيديو/صورة/صوت/نص)، الحالة، المنشئ، الوحدة الإعلامية، الفترة الزمنية
- **رفع محتوى جديد** (مباشرة أو من تصوير)
- **تفاصيل المحتوى** — فيها: الوسوم، المهام المرتبطة، عدد مرات إعادة الاستخدام، تاريخ إعادة الاستخدام
- **زر "إعادة استخدام"** — يفتح نموذج لاختيار المهمة الجديدة
- **زر "تعليم كنهائي"** — لما يتعلم كنهائي بيتأرشف تلقائي

### 7. الإشعارات
- **أيقونة بالشريط العلوي** مع فقاعة عدد غير المقروءة (`GET /api/notifications/unread-count`)
- **قائمة منسدلة** بالإشعارات الأخيرة
- **صفحة إشعارات كاملة** مع كل الإشعارات
- **الضغط على إشعار** يعلمه كمقروء ويوديك للعنصر المرتبط (مهمة/أوردر/محتوى)
- **زر "قراءة الكل"**
- **إشعارات لحظية** عبر ويب سوكت — لما يوصل إشعار جديد يظهر مباشرة بدون ما المستخدم يحدث الصفحة

### 8. إدارة المستخدمين (للإدارة فقط)
- **قائمة المستخدمين** مع أدوارهم
- **إضافة مستخدم جديد** (اسم، إيميل، كلمة سر، دور، أيام عمل، وقت بداية/نهاية)
- **تعديل مستخدم** + تعيين كلمة سر
- **إدارة أدوار المستخدم** — إضافة وحذف أدوار (كل مستخدم ممكن يكون عنده أكثر من دور)
- **عرض صلاحيات المستخدم** (مجمعة من كل أدواره)
- **مؤشرات أداء الموظف** (`GET /api/kpi/users/:userId`) — عدد المهام، نسبة الالتزام، المحتوى المنتج، استخدام الذكاء الاصطناعي

### 9. البرامج والحلقات
- **قائمة البرامج** مع الوحدة الإعلامية
- **تفاصيل البرنامج** — الحلقات + فريق العمل (مذيع، معد، منتج...)
- **قائمة الحلقات** — استخدم النقطة المخصبة (`GET /api/portal/episodes/enriched`) اللي بترجع الحالة من الأوردر وعدد الضيوف وعدد المحتوى
- **تفاصيل الحلقة** (`GET /api/portal/episodes/:id/full`) — الضيوف + المهام + المحتوى
- **إدارة الضيوف** — إضافة وبحث وربط بالحلقات

### 10. الأقسام والفرق
- **قائمة الأقسام** مع فرقها
- **إدارة أعضاء الفرق** — إضافة وحذف

## ملاحظات تقنية مهمة

### المصادقة والصلاحيات
- بعد تسجيل الدخول — استدعي `GET /api/auth/me` لجلب صلاحيات المستخدم
- اعرض/اخفي الأقسام والأزرار حسب الصلاحيات
- لوحة التحكم ومؤشرات الأداء وإدارة المستخدمين — فقط لمن عنده صلاحية `kpi.view` أو `users.manage`
- باقي الأقسام — لكل الموظفين

### الإشعارات اللحظية
```javascript
import { io } from 'socket.io-client';
const socket = io('https://media-center-management-system.onrender.com');
socket.emit('authenticate', token);
socket.on('notification', (data) => { /* اعرض الإشعار */ });
```

### الربط مع نظام الأخبار
- المهام المتعلقة بالأخبار — لما الموظف يضغط عليها يفتح نظام الأخبار بتبويب جديد
- أدوات الذكاء الاصطناعي (تلخيص، إعادة صياغة، توليد أفكار، تحويل صوت...) متاحة بنظام الأخبار

### اللغة والاتجاه
- الواجهة بالعربية
- الاتجاه من اليمين لليسار (RTL)
- أسماء الموظفين والبرامج والأقسام كلها بالعربية

### التصميم
- تصميم احترافي ونظيف مناسب لبيئة عمل إعلامية
- ألوان هادئة ومريحة للعين
- متجاوب مع كل الشاشات
- أيقونات واضحة وأزرار مرتبة
