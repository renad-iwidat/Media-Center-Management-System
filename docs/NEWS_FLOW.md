# 📰 فلو الأخبار الكامل — من السحب حتى النشر الخارجي

> **آخر تحديث:** يونيو 2026  
> **الغرض:** شرح رحلة الخبر الكاملة + شروط ظهوره في كل صفحة بالفرونت

---

## 🎯 ملخص المراحل

```
1️⃣ السحب من API خارجي (NewsDesk)
2️⃣ إعادة الصياغة/التنظيف (Rewriting - Background)
3️⃣ التصنيف والتوجيه (Classification + Flow Routing)
4️⃣ قسم التحرير (Editorial Queue)
5️⃣ قسم النشر (Ready to Publish)
6️⃣ النشر الخارجي (External Publish - Najah/HGaza)
7️⃣ الأرشيف (Archive)
```

---

## 🔄 رحلة الخبر الكاملة

```
┌────────────────────────────────────────────────────────────────┐
│  NewsDesk API (مصادر خارجية)                                    │
└──────────────────────────┬─────────────────────────────────────┘
                           ↓
┌──────────────────────────────────────────────────────────────────┐
│  1️⃣ السحب (Fetcher - كل 15 دقيقة)                              │
│  • جلب قائمة المقالات لكل وحدة إعلامية                          │
│  • جلب التفاصيل الكاملة (نص + تصنيفات)                          │
│  • فحص التكرار (newsdesk_article_id)                             │
│  • حفظ بـ raw_data (fetch_status='fetched', is_rewritten=false)  │
└──────────────────────────┬───────────────────────────────────────┘
                           ↓
┌──────────────────────────────────────────────────────────────────┐
│  2️⃣ إعادة الصياغة (Article Rewriter - Background)               │
│  • يأخذ أخبار بـ is_rewritten=false                              │
│  • يعيد صياغة المحتوى بالذكاء الاصطناعي                         │
│  • يحدّث: content = النص المعاد صياغته, is_rewritten = true      │
│  ⚠️ خبر بدون rewriting لا يظهر بقسم النشر                        │
└──────────────────────────┬───────────────────────────────────────┘
                           ↓
┌──────────────────────────────────────────────────────────────────┐
│  3️⃣ التصنيف والتوجيه (Classifier + FlowRouter)                  │
│  • تصنيف AI إذا ما كان مصنف                                     │
│  • فحص اكتمال (≥100 حرف + صورة)                                 │
│  • تحديد نوع الفلو من category.flow:                             │
│    - automated (اقتصاد، رياضة، صحة، تكنولوجيا، ثقافة، بيئة)    │
│    - editorial (سياسي، محلي، دولي)                               │
│  • التوزيع على الوحدات الإعلامية المرتبطة                        │
└──────────────────────────┬───────────────────────────────────────┘
                           ↓
              ┌────────────┴────────────┐
              │                         │
         ❌ ناقص                   ✅ مكتمل
              │                         │
              ↓                         ↓
   editorial_queue              ┌───────┴───────┐
   status='incomplete'          │               │
                           editorial         automated
                                │               │
                                ↓               ↓
                         status='pending'   status='approved'
                         (ينتظر المحرر)    (فوري → published)
                                │               │
                         المحرر يوافق           │
                                │               │
                                ↓               ↓
                         status='approved'      │
                                │               │
                                └───────┬───────┘
                                        ↓
┌──────────────────────────────────────────────────────────────────┐
│  5️⃣ قسم النشر (Ready to Publish)                                │
│  • editorial_queue.status = 'approved'                           │
│  • AND raw_data.is_rewritten = true ← ⚠️ شرط جديد              │
│  • AND publish_status != 'archived'                              │
└──────────────────────────┬───────────────────────────────────────┘
                           ↓
┌──────────────────────────────────────────────────────────────────┐
│  6️⃣ النشر الخارجي (Auto-Publish)                                │
│  • تلقائي: السكيدولر ينشر كل الأخبار الأوتوماتيكية المعاد       │
│    صياغتها على المواقع المفعّل فيها auto_enabled                  │
│  • يدوي: المحرر يختار خبر → يختار موقع → يحدد إعدادات النشر     │
│  • إعدادات لكل موقع: auto_publish (مباشر/مسودة) + pin (0-5)     │
└──────────────────────────┬───────────────────────────────────────┘
                           ↓
┌──────────────────────────────────────────────────────────────────┐
│  7️⃣ الأرشيف                                                     │
│  • بعد النشر بنجاح على منصة واحدة على الأقل                     │
│  • publish_status = 'archived'                                   │
└──────────────────────────────────────────────────────────────────┘
```

### 3. أخبار غير مكتملة (Incomplete)

| البند | التفاصيل |
|-------|---------|
| **الصلاحية** | `news.edit` |
| **المصدر** | `/api/data/articles/incomplete` |
| **شروط الظهور** | `raw_data.is_incomplete = true` أو `editorial_queue.status = 'incomplete'` |
| **ماذا يعني "ناقص"** | محتوى < 100 حرف أو بدون صورة |
| **الإجراء** | المحرر يكمل المحتوى ويضيف صورة → يحفظ ويرسل |

**الفلو:**
```
خبر ناقص → المحرر يكمله → status يتغير لـ 'pending' أو 'approved' (حسب التصنيف)
```

---

### 4. قسم التحرير (Queue / Editorial Studio)

| البند | التفاصيل |
|-------|---------|
| **الصلاحية** | `news.edit` |
| **المصدر** | `/api/flow/editorial` |
| **شروط الظهور** | `editorial_queue.status IN ('pending', 'in_review')` |
| **الإجراء** | المحرر يراجع → يوافق أو يرفض |

**الفلو:**
```
خبر مكتمل + تحريري → pending → المحرر يراجع → approved/rejected
خبر مكتمل + أوتوماتيكي → pending → النظام يوافق تلقائياً → approved
```

**ملاحظة:** الأخبار الأوتوماتيكية تظهر هنا لحظياً فقط قبل أن يوافق عليها النظام.

---

### 5. قسم النشر (Published / Ready to Publish)

| البند | التفاصيل |
|-------|---------|
| **الصلاحية** | `news.publish` |
| **المصدر** | `/api/flow/ready-to-publish` |
| **شروط الظهور (كلها مطلوبة)** | |
| 1. | `editorial_queue.status = 'approved'` |
| 2. | `raw_data.is_rewritten = true` ← الخبر لازم يكون اتعمله rewriting |
| 3. | `raw_data.publish_status != 'archived'` |
| **الإجراء** | المحرر ينشر يدوياً على المواقع الخارجية أو يؤرشف |

**⚠️ مهم:** خبر approved لكن `is_rewritten = false` **لا يظهر** بقسم النشر. لازم الـ Background Rewriter يعالجه أولاً.

**الفلو:**
```
خبر approved + is_rewritten=true → يظهر بقسم النشر
     ↓
المحرر يختار "نشر على موقع خارجي"
     ↓
يختار الموقع (النجاح / هنا غزة)
     ↓
يحدد: التصنيف + الوضع (نشر مباشر/مسودة) + Pin
     ↓
ينشر → يحفظ بـ auto_publish_log
     ↓
بعد النشر بنجاح → يمكن أرشفته
```

### 8. إعدادات النظام (Settings)

| البند | التفاصيل |
|-------|---------|
| **الصلاحية** | `news.settings` |
| **المصدر** | `/api/settings/toggles` + `/api/auto-publish/status` |
| **المحتوى** | |

**إعدادات السحب:**
- تشغيل/إيقاف النظام (السحب + التصنيف + التوجيه)
- الفترة بين كل سحب (دقائق)
- عدد الأخبار لكل مصدر

**إعدادات النشر الخارجي (لكل موقع):**
- ✋ يدوي (manual_enabled) — المحرر يقدر ينشر يدوياً
- ⚡ تلقائي (auto_enabled) — السكيدولر ينشر تلقائياً
- وضع النشر الافتراضي (default_auto_publish):
  - `true` = نشر مباشر على الموقع
  - `false` = حفظ كمسودة (Draft)
- التثبيت (default_pin): 0-5
  - `0` = بدون تثبيت
  - `1-4` = مثبت بالصفحة الرئيسية
  - `5` = أول خبر بالصفحة الرئيسية (صورة كبيرة)

## 🗄️ حقول قاعدة البيانات المهمة

### جدول `raw_data`

| الحقل | النوع | الوظيفة |
|-------|-------|---------|
| `fetch_status` | varchar | fetched → processed → published |
| `is_incomplete` | boolean | ناقص (< 100 حرف أو بدون صورة) |
| `is_rewritten` | boolean | هل اتعمله rewriting بالـ AI |
| `publish_status` | varchar | draft / published_external / archived |
| `category_id` | integer | التصنيف (يحدد الفلو: automated vs editorial) |
| `media_unit_id` | integer | الوحدة الإعلامية اللي سحبته |

### جدول `editorial_queue`

| الحقل | النوع | الوظيفة |
|-------|-------|---------|
| `status` | varchar | incomplete / pending / in_review / approved / rejected |
| `media_unit_id` | integer | الوحدة المستهدفة |
| `raw_data_id` | integer | ربط مع الخبر الأصلي |

### جدول `auto_publish_targets`

| الحقل | النوع | الوظيفة |
|-------|-------|---------|
| `manual_enabled` | boolean | النشر اليدوي مفعّل |
| `auto_enabled` | boolean | النشر التلقائي مفعّل |
| `default_auto_publish` | boolean | نشر مباشر (true) أو مسودة (false) |
| `default_pin` | integer | 0-5 تثبيت بالصفحة الرئيسية |
| `auth_type` | varchar | bearer (هنا غزة) / token (النجاح) |
| `category_mappings` | jsonb | ربط التصنيفات المحلية بالخارجية |

## ⚡ النشر التلقائي vs اليدوي

### النشر التلقائي (Scheduler)

```
شروط النشر التلقائي على موقع خارجي:
1. auto_publish_enabled = true (master switch)
2. الهدف: auto_enabled = true
3. الخبر: categories.flow = 'automated'
4. الخبر: is_rewritten = true
5. الخبر: لم يُنشر على هذا الهدف من قبل

إعدادات تُرسل مع الطلب:
• auto_publish = target.default_auto_publish (نشر مباشر أو مسودة)
• pin = target.default_pin (0-5)
• category_id = من category_mappings أو default_category_id
• keywords = تاجز AI أو من العنوان
```

### النشر اليدوي (المحرر)

```
شروط النشر اليدوي:
1. الهدف: manual_enabled = true (أو is_enabled = true)
2. الخبر: approved + is_rewritten = true (ظاهر بقسم النشر)
3. لم يُنشر على هذا الهدف من قبل

الفلو:
المحرر → يضغط "نشر خارجي" → يختار الموقع → dialog إعدادات:
  • التصنيف (من قائمة تصنيفات الموقع الخارجي)
  • الوضع: نشر مباشر أو مسودة
  • Pin: 0-5
→ يأكد → ينشر
```

## 🔗 مواقع النشر الحالية

| الموقع | الوحدة | API | Auth | auto_publish | pin |
|--------|--------|-----|------|-------------|-----|
| موقع هنا غزة | هنا غزة | `hgaza.nn.ps/api/v1/automation/news` | Bearer | `true` (مباشر) | 0 |
| موقع النجاح | النجاح | `nn.najah.edu/api/v1/news/article/` | Token | `false` (مسودة) | 0 |

**curl مثال (النجاح):**
```bash
curl -X POST \
  -H "Authorization: Token YOUR_TOKEN" \
  -F "title=عنوان الخبر" \
  -F "category_id=12" \
  --form-string "content=<p>محتوى الخبر</p>" \
  -F "image=@/path/to/image.jpg" \
  -F "image_caption=وصف الصورة" \
  -F "keywords=كلمة1,كلمة2,كلمة3" \
  -F "auto_publish=true" \
  -F "pin=0" \
  https://nn.najah.edu/api/v1/news/article/
```

- `auto_publish=true` → ينشر مباشرة على الموقع
- `auto_publish=false` → يحفظ كمسودة (Draft)
- `pin=0` → بدون تثبيت
- `pin=1-5` → مثبت بالصفحة الرئيسية (5 = أول خبر، صورة كبيرة)
