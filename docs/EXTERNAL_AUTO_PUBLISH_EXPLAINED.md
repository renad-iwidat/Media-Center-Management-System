## 🔍 السبب

هذا الخبر **خاص** ولديه معاملة مختلفة لأنه:

### 1️⃣ إدخال يدوي (`source_type_id = 6`)

```typescript

  6,  // user_input_text    ← هذا الخبر

```

**الإدخال اليدوي له قواعد خاصة**:
- 🔵 يذهب **دائماً** للمحرر (حتى لو كان التصنيف آلي)
- ✅ المحرر يتحكم بشكل كامل في النشر
- ⚡ يمكن نشره رغم أنه غير مكتمل (قرار المحرر)

### 2️⃣ المحرر وافق عليه يدوياً

رغم أن الخبر غير مكتمل، **المحرر**:
1. ✅ راجعه
2. ✅ وافق عليه (ضغط "موافقة")
3. ✅ تم نشره في `published_items`

### 3️⃣ النشر التلقائي الخارجي

بعد وصول الخبر لـ `published_items`، يعمل **نظام النشر الخارجي التلقائي**:

```
كل 10 دقائق (Scheduler):
  ↓
1. البحث عن أخبار في published_items
  ↓
2. التحقق من وجود أهداف نشر خارجية (auto_publish_targets)
  ↓
3. نشر الخبر على الموقع الخارجي (مثل موقع غزة)
  ↓
4. تحديث publish_status = 'published_external'
```

### ✅ متى يُنشر على الموقع الخارجي؟

| الشرط | مطلوب؟ |

| **يوجد `auto_publish_target` مفعّل** | ✅ نعم |

## 💡 لماذا هذا التصميم؟

### 1. الثقة في المحرر
```
الإدخال اليدوي = محتوى موثوق
← المحرر كتبه بنفسه
← يعرف ما يفعل
← لا حاجة لفرض قيود صارمة
```

### 2. المرونة
```
بعض الأخبار العاجلة قصيرة بطبيعتها:
- "استشهاد مواطن برصاص الاحتلال"
- "إصابة 4 جنود في غزة"
- "اقتحام بلدة سلواد"

← 50-80 حرف قد تكون كافية
← المحرر يقرر
```

### 3. النشر السريع
```
خبر عاجل + إدخال يدوي + موافقة المحرر
← يُنشر فوراً بدون عوائق
← لا انتظار لإكمال الشروط
```

- الإدخال اليدوي = محتوى موثوق

**لا**. فقط إذا:
