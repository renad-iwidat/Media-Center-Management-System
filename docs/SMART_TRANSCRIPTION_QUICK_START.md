# التفريغ الذكي - البدء السريع

## ما هو التفريغ الذكي؟

نظام ذكي يحول ملف صوت أو فيديو إلى 6 منتجات تحريرية احترافية:
1. ملخص تنفيذي
2. خبر صحفي
3. تقرير صحفي
4. منشورات سوشيال ميديا
5. مقاطع فيديو مع تايم كود
6. تنبيهات سياسة التحرير

## الخطوات الأساسية

### 1. الوصول إلى التاب
```
القائمة الجانبية → أدوات الذكاء الاصطناعي → التفريغ الذكي
```

### 2. رفع الملف
- اسحب ملف صوت أو فيديو
- أو انقر لاختيار ملف من جهازك
- الملف يجب أن يكون بين 1 و 60 دقيقة

### 3. اختيار المخرجات
```
☑ ملخص تنفيذي
☑ خبر صحفي
☐ تقرير صحفي
☑ منشورات سوشيال ميديا (10)
☑ مقاطع فيديو (10)
☑ تنبيهات سياسة التحرير
```

### 4. إضافة معلومات
- **سياسة التحرير**: أدخل سياسة قناتك (مرة واحدة فقط)
- **معلومات إضافية**: أرقام، إحصائيات، أو تفاصيل محددة

### 5. توليد المخرجات
- اضغط "توليد المخرجات"
- انتظر حتى ينتهي (عادة 2-5 دقائق)

### 6. تحميل الملف
- معاين كل مخرج
- اضغط "تحميل الملف الموحد"
- ستحصل على ملف نصي يحتوي على كل شيء

## أمثلة

### مثال 1: منشورات سوشيال ميديا
```
تويتر:
وزير الخارجية يعلن عن قرار جديد بشأن العلاقات الدولية

فيسبوك:
في مؤتمر صحفي اليوم، أعلن وزير الخارجية عن قرار تاريخي...

إنستجرام:
🔴 عاجل: وزير الخارجية يكشف عن خطة جديدة
```

### مثال 2: مقاطع فيديو
```
01:04 — 02:30 - تصريح وزير الخارجية
الوزير أعلن عن قرار جديد بشأن العلاقات الدولية

02:45 — 03:15 - رد المعارضة
ممثل المعارضة رد على التصريح بقول...

03:30 — 04:00 - تحليل الخبراء
الخبير الاقتصادي علق على القرار قائلاً...
```

## نصائح مهمة

### ✅ افعل
- استخدم ملفات عالية الجودة
- أدخل سياسة التحرير بدقة
- أضف معلومات إضافية مهمة
- راجع المخرجات قبل النشر

### ❌ لا تفعل
- لا ترفع ملفات أكبر من 1 GB
- لا تتوقع نتائج مثالية من ملفات منخفضة الجودة
- لا تعدّل سياسة التحرير بين المخرجات
- لا تنسخ المخرجات مباشرة بدون مراجعة

## الأسئلة الشائعة

### س: كم من الوقت يستغرق التفريغ؟
ج: عادة 2-5 دقائق حسب طول الملف وجودة الصوت

### س: هل يمكن تعديل المخرجات بعد التوليد؟
ج: نعم، يمكنك معاينة كل مخرج وتحريره قبل التحميل

### س: هل يمكن استخدام لغات أخرى؟
ج: حالياً يدعم العربية فقط، لكن سيتم إضافة لغات أخرى قريباً

### س: ما هي صيغ الملفات المدعومة؟
ج: mp3, mp4, wav, m4a, ogg, flac, webm

### س: هل البيانات آمنة؟
ج: نعم، جميع البيانات مشفرة وآمنة
