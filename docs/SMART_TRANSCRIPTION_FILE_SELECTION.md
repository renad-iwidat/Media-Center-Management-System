# Smart Transcription - File Selection Update

## التحديث الجديد

تم تحديث مكون **Smart Transcription** ليعمل مثل **Audio Lab** - حيث يعرض الملفات الصوتية والفيديوهات المرفوعة مباشرة من Upload Files بدلاً من رفع ملفات جديدة.

## المميزات الجديدة

### 1. عرض الملفات المرفوعة
- **قائمة الملفات**: تعرض جميع الملفات الصوتية والفيديوهات المرفوعة مسبقاً
- **البحث والفلترة**: 
  - البحث بالاسم
  - فلترة حسب النوع (الكل / صوت / فيديو)
- **معلومات الملف**:
  - اسم الملف
  - حجم الملف
  - تاريخ الرفع

### 2. معاينة الملفات
- **الملفات الصوتية**: مشغل صوت مدمج للاستماع قبل المعالجة
- **الملفات الفيديو**: عارض فيديو في نافذة منفصلة

### 3. المعالجة المباشرة
- اختر ملف من القائمة
- انقر على زر "بدء التفريغ"
- سيتم تفريغ الملف وتوليد المخرجات تلقائياً

### 4. رفع ملفات جديدة
- زر "رفع ملف جديد" في أسفل القائمة
- يمكن رفع ملفات صوتية أو فيديو جديدة
- سيتم معالجتها مباشرة بعد الرفع

## الحالات المختلفة

### 1. عند بدء التطبيق
- يتم جلب جميع الملفات الصوتية والفيديوهات المرفوعة
- تظهر في القائمة مع معلوماتها

### 2. عند اختيار ملف
- يتم تحديد الملف (يظهر بلون مختلف)
- يمكن معاينة الملف (صوت أو فيديو)

### 3. عند النقر على "بدء التفريغ"
- يتم إرسال الملف للمعالجة
- يظهر مؤشر التحميل
- بعد الانتهاء يظهر التفريغ والمخرجات

### 4. عند رفع ملف جديد
- يتم رفع الملف إلى S3
- يتم معالجته مباشرة
- يظهر في القائمة بعد الانتهاء

## الـ API Methods المستخدمة

```typescript
// جلب الملفات الصوتية
api.getAudioFiles()

// جلب الملفات الفيديو
api.getVideoFiles()

// معالجة الملف
api.smartTranscriptionProcess({
  fileUrl: string,
  fileType: 'audio' | 'video',
  language: 'ar',
  outputs: [...],
  editorialPolicy: string,
  customInfo: string
})

// توليد المخرجات
api.smartTranscriptionGenerateOutputs({
  transcript: string,
  outputs: [...],
  editorialPolicy: string,
  customInfo: string
})

// تصدير الملف الموحد
api.smartTranscriptionExport({
  outputs: [...],
  editorialPolicy: string,
  customInfo: string
})
```

## ملاحظات مهمة

1. **الملفات المرفوعة**: يتم جلبها من S3 تلقائياً عند تحميل المكون
2. **المعاينة**: الملفات الصوتية تعرض مشغل صوت، والفيديوهات تعرض في نافذة منفصلة
3. **الرفع الجديد**: يمكن رفع ملفات جديدة من خلال الزر في أسفل القائمة
4. **المعالجة**: تتم المعالجة بنفس الطريقة سواء كان الملف مرفوع مسبقاً أو جديد

## الخطوات التالية

1. اختبر المكون مع ملفات صوتية وفيديو مختلفة
2. تأكد من أن المعاينة تعمل بشكل صحيح
3. اختبر البحث والفلترة
4. اختبر رفع ملفات جديدة
