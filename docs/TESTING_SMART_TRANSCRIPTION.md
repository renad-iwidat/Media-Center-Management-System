# اختبار Smart Transcription

## قائمة الاختبار

### 1. اختبار عرض الملفات المرفوعة
- [ ] تحميل الصفحة
- [ ] تظهر قائمة الملفات الصوتية والفيديوهات
- [ ] يظهر عدد الملفات بشكل صحيح
- [ ] تظهر معلومات الملف (الاسم، الحجم، التاريخ)

### 2. اختبار البحث والفلترة
- [ ] البحث بالاسم يعمل بشكل صحيح
- [ ] فلتر "الكل" يعرض جميع الملفات
- [ ] فلتر "صوت" يعرض الملفات الصوتية فقط
- [ ] فلتر "فيديو" يعرض الملفات الفيديو فقط

### 3. اختبار معاينة الملفات
- [ ] معاينة الملفات الصوتية تعمل
- [ ] معاينة الملفات الفيديو تعمل
- [ ] يمكن تشغيل وإيقاف المعاينة

### 4. اختبار رفع ملفات جديدة
- [ ] زر "رفع ملف جديد" يعمل
- [ ] يمكن اختيار ملف صوتي
- [ ] يمكن اختيار ملف فيديو
- [ ] الملف الجديد يظهر في القائمة

### 5. اختبار سياسات التحرير
- [ ] قائمة السياسات تظهر بشكل صحيح
- [ ] يمكن اختيار سياسة من القائمة
- [ ] السياسة المختارة تظهر أسفل القائمة
- [ ] يمكن إضافة سياسة جديدة
- [ ] يمكن تحرير سياسة موجودة
- [ ] يمكن حذف سياسة

### 6. اختبار المعلومات الإضافية
- [ ] يمكن كتابة معلومات إضافية
- [ ] المعلومات تُحفظ بشكل صحيح
- [ ] يمكن تعديل المعلومات

### 7. اختبار اختيار المخرجات
- [ ] يمكن تحديد/إلغاء تحديد المخرجات
- [ ] حقول العدد تظهر للمخرجات المتعددة
- [ ] يمكن تغيير العدد

### 8. اختبار المعالجة
- [ ] اختيار ملف + النقر على "بدء التفريغ" يعمل
- [ ] يظهر مؤشر التحميل أثناء المعالجة
- [ ] التفريغ يظهر بعد الانتهاء
- [ ] المخرجات تظهر بعد الانتهاء

### 9. اختبار معاينة المخرجات
- [ ] يمكن النقر على أي مخرج لمعاينته
- [ ] نافذة المعاينة تظهر بشكل صحيح
- [ ] يمكن إغلاق نافذة المعاينة

### 10. اختبار تحميل الملف الموحد
- [ ] زر "تحميل الملف الموحد" يعمل
- [ ] يتم تحميل ملف بصيغة صحيحة
- [ ] الملف يحتوي على جميع المخرجات

## اختبار API

### 1. اختبار إرسال البيانات الصحيحة
```bash
curl -X POST http://localhost:3000/api/ai-hub/smart-transcription/process \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{
    "fileUrl": "https://...",
    "fileType": "audio",
    "language": "ar",
    "outputs": [
      { "type": "executive_summary", "enabled": true },
      { "type": "news_article", "enabled": true }
    ],
    "editorialPolicy": "نص السياسة",
    "customInfo": "معلومات إضافية"
  }'
```

### 2. التحقق من الاستجابة
- [ ] الاستجابة تحتوي على `success: true`
- [ ] الاستجابة تحتوي على `transcript`
- [ ] الاستجابة تحتوي على `outputs`
- [ ] الاستجابة تحتوي على `metadata`

### 3. التحقق من استخدام السياسة
- [ ] السياسة تُستخدم في توليد المخرجات
- [ ] المخرجات تتبع السياسة المختارة
- [ ] تنبيهات السياسة تظهر بشكل صحيح

## اختبار الأداء

### 1. سرعة التحميل
- [ ] الصفحة تحمل في أقل من 3 ثوان
- [ ] قائمة الملفات تحمل بسرعة

### 2. سرعة المعالجة
- [ ] معالجة ملف صوتي 5 دقائق تستغرق أقل من 30 ثانية
- [ ] معالجة ملف فيديو 5 دقائق تستغرق أقل من 60 ثانية

### 3. استهلاك الذاكرة
- [ ] الصفحة لا تستهلك ذاكرة كبيرة
- [ ] لا توجد تسريبات ذاكرة

## اختبار الأخطاء

### 1. ملف غير صحيح
- [ ] رسالة خطأ واضحة تظهر
- [ ] التطبيق لا يتعطل

### 2. ملف كبير جداً
- [ ] رسالة خطأ واضحة تظهر
- [ ] التطبيق لا يتعطل

### 3. انقطاع الاتصال
- [ ] رسالة خطأ واضحة تظهر
- [ ] يمكن إعادة المحاولة

### 4. خطأ في الخادم
- [ ] رسالة خطأ واضحة تظهر
- [ ] التطبيق لا يتعطل

## ملاحظات الاختبار

### ملاحظات عامة
- تأكد من تسجيل الدخول قبل الاختبار
- استخدم ملفات اختبار حقيقية
- اختبر مع ملفات بأحجام مختلفة

### ملاحظات خاصة بالسياسات
- اختبر مع سياسات مختلفة
- تأكد من أن السياسة تُستخدم بشكل صحيح
- اختبر مع سياسة فارغة

### ملاحظات خاصة بالمخرجات
- اختبر مع مخرجات مختلفة
- اختبر مع عدد مختلف من المخرجات
- تأكد من أن جميع المخرجات تُولد بشكل صحيح

## النتائج المتوقعة

### عند اختيار ملف وبدء المعالجة
1. يظهر مؤشر التحميل
2. يتم إرسال الطلب إلى الخادم مع السياسة والمعلومات الإضافية
3. يتم استقبال الاستجابة
4. يظهر التفريغ والمخرجات

### عند معاينة مخرج
1. تظهر نافذة المعاينة
2. يظهر محتوى المخرج بشكل صحيح
3. يمكن إغلاق النافذة

### عند تحميل الملف الموحد
1. يتم تحميل ملف بصيغة صحيحة
2. الملف يحتوي على جميع المخرجات
3. الملف يحتوي على السياسة والمعلومات الإضافية
