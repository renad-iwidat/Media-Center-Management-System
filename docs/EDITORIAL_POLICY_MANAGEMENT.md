# إدارة سياسات التحرير - دليل شامل

## نظرة عامة

تم إضافة نظام متكامل لإدارة سياسات التحرير في نظام التفريغ الذكي. يسمح هذا النظام بـ:
- عرض السياسات المحفوظة
- إضافة سياسات جديدة
- تحرير السياسات الموجودة
- حذف السياسات
- اختيار السياسة المطلوبة للاستخدام

## المميزات

### 1. عرض السياسات الموجودة
- قائمة منسدلة تعرض جميع السياسات المحفوظة
- عرض اسم السياسة والمحتوى الأول منها
- اختيار سريع من القائمة

### 2. إضافة سياسة جديدة
- نموذج بسيط لإضافة سياسة جديدة
- حقل لاسم السياسة
- حقل لمحتوى السياسة
- حفظ تلقائي في قاعدة البيانات

### 3. تحرير السياسات
- تحرير أي سياسة موجودة
- تحديث الاسم والمحتوى
- حفظ التغييرات تلقائياً

### 4. حذف السياسات
- حذف السياسات غير المستخدمة
- تأكيد قبل الحذف
- تحديث القائمة تلقائياً

### 5. اختيار السياسة
- اختيار السياسة من القائمة
- عرض السياسة المختارة
- استخدام السياسة في التفريغ الذكي

## كيفية الاستخدام

### إضافة سياسة جديدة

1. **افتح التفريغ الذكي**
   - انتقل إلى "التفريغ الذكي" من القائمة الجانبية

2. **انقر على قائمة السياسات**
   - اضغط على "اختر سياسة..." في قسم سياسة التحرير

3. **اختر "إضافة سياسة جديدة"**
   - اضغط على الزر في أسفل القائمة

4. **أدخل بيانات السياسة**
   - اسم السياسة: "سياسة الأخبار الرئيسية"
   - محتوى السياسة: "ممنوع استخدام الكلمات النابية، ممنوع التحيز السياسي..."

5. **اضغط "إضافة"**
   - سيتم حفظ السياسة تلقائياً

### اختيار سياسة موجودة

1. **افتح قائمة السياسات**
   - اضغط على "اختر سياسة..."

2. **اختر السياسة المطلوبة**
   - انقر على السياسة من القائمة

3. **سيتم تطبيق السياسة تلقائياً**
   - ستظهر السياسة المختارة في الأسفل

### تحرير سياسة موجودة

1. **افتح قائمة السياسات**
   - اضغط على "اختر سياسة..."

2. **اضغط على أيقونة التحرير**
   - انقر على أيقونة القلم بجانب السياسة

3. **عدّل البيانات**
   - غيّر الاسم أو المحتوى حسب الحاجة

4. **اضغط "تحديث"**
   - سيتم حفظ التغييرات تلقائياً

### حذف سياسة

1. **افتح قائمة السياسات**
   - اضغط على "اختر سياسة..."

2. **اضغط على أيقونة الحذف**
   - انقر على أيقونة السلة بجانب السياسة

3. **أكّد الحذف**
   - اضغط "نعم" في رسالة التأكيد

4. **سيتم حذف السياسة**
   - ستختفي من القائمة

## أمثلة على السياسات

### مثال 1: سياسة الأخبار الرئيسية
```
اسم السياسة: سياسة الأخبار الرئيسية

محتوى السياسة:
- ممنوع استخدام الكلمات النابية أو المسيئة
- ممنوع التحيز السياسي أو الديني
- يجب التحقق من المصادر قبل النشر
- يجب نسب التصريحات لقائليها
- ممنوع نشر معلومات شخصية حساسة
- يجب احترام خصوصية الأفراد
```

### مثال 2: سياسة الأخبار الاقتصادية
```
اسم السياسة: سياسة الأخبار الاقتصادية

محتوى السياسة:
- يجب التحقق من الأرقام الاقتصادية من مصادر رسمية
- يجب شرح المصطلحات الاقتصادية المعقدة
- ممنوع نشر معلومات سرية عن الشركات
- يجب الإشارة إلى تضارب المصالح إن وجد
- يجب عدم الترويج لأي منتج أو خدمة
```

### مثال 3: سياسة الأخبار الرياضية
```
اسم السياسة: سياسة الأخبار الرياضية

محتوى السياسة:
- يجب احترام جميع الفرق والرياضيين
- ممنوع استخدام لغة عنيفة أو مسيئة
- يجب التحقق من النتائج من مصادر رسمية
- يجب عدم نشر معلومات شخصية عن الرياضيين
- يجب احترام قرارات الحكام
```

### API Endpoints
```
GET /api/news/editorial-policies
- جلب جميع السياسات

POST /api/news/editorial-policies
- إضافة سياسة جديدة

PUT /api/news/editorial-policies/:name
- تحديث سياسة موجودة

DELETE /api/news/editorial-policies/:name
- حذف سياسة
```

## التكامل مع التفريغ الذكي

### كيفية الاستخدام
1. اختر السياسة المطلوبة من قائمة السياسات
2. سيتم استخدام السياسة في توليد المخرجات
3. سيتم التحقق من المخرجات مقابل السياسة
4. سيتم تنبيهك بأي مخالفات

### مثال على الاستخدام
```
1. اختر "سياسة الأخبار الرئيسية"
2. رفع ملف صوت
3. اختر المخرجات المطلوبة
4. اضغط "توليد المخرجات"
5. سيتم التحقق من المخرجات مقابل السياسة
6. ستظهر أي مخالفات في "تنبيهات سياسة التحرير"
```

## الأسئلة الشائعة

### س: هل يمكن استخدام سياسة واحدة لعدة مشاريع؟
ج: نعم، السياسات مشتركة بين جميع المستخدمين

### س: هل يمكن حذف سياسة مستخدمة؟
ج: نعم، لكن سيتم تنبيهك بأن السياسة قيد الاستخدام

### س: هل يمكن تصدير السياسات؟
ج: حالياً لا، لكن سيتم إضافة هذه الميزة قريباً

### س: هل يمكن استيراد سياسات من ملف؟
ج: حالياً لا، لكن سيتم إضافة هذه الميزة قريباً

### س: كم عدد السياسات التي يمكن إضافتها؟
ج: لا يوجد حد أقصى، يمكنك إضافة عدد غير محدود من السياسات
