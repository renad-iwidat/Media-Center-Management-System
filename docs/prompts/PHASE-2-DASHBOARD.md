## تصميم الصفحة

### القسم الأول — فلترة بالفترة الزمنية
- حقلين تاريخ: "من" و "إلى"
- أزرار سريعة: "هاد الأسبوع" / "هاد الشهر" / "آخر 3 شهور" / "الكل"
- لما يتغير التاريخ — يعيد سحب البيانات

### القسم الثاني — بطاقات الملخص (4 بطاقات بصف واحد)

**بطاقة الأوردرات:**
- الرقم الكبير: إجمالي الأوردرات
- تحته: مكتملة (أخضر) / جارية (أزرق) / معلقة (رمادي) / متأخرة (أحمر)
- نسبة الإنجاز بشريط تقدم

**بطاقة المهام:**
- نفس الشكل — إجمالي + توزيع الحالات + نسبة الإنجاز

**بطاقة المحتوى:**
- إجمالي المحتوى + الحجم بالميغابايت + المؤرشف

**بطاقة الأداء:**
- متوسط وقت الإنجاز (بالدقائق أو الساعات)
- نسبة الالتزام بالمواعيد (بشريط دائري)

### القسم الثالث — رسم بياني للمقارنات الشهرية
- رسم بياني خطي أو شريطي
- 3 خطوط: أوردرات (أزرق) / مهام (أخضر) / محتوى (برتقالي)
- المحور الأفقي: الأشهر
- المحور العمودي: العدد
- البيانات من: `GET /api/kpi/trends?months=6`

### القسم الرابع — أفضل الموظفين (جدول)
- الاسم + الدور + المهام المكتملة + نسبة الالتزام
- مرتب من الأفضل للأقل
- أول 5 موظفين

### القسم الخامس — إعادة الاستخدام
- إجمالي مرات إعادة الاستخدام (رقم كبير)
- أكثر 5 محتويات إعادة استخدام (جدول صغير: العنوان + عدد المرات)

### القسم السادس — المهام المتأخرة
```
GET /api/tasks/overdue
Authorization: Bearer TOKEN
```
- جدول بالمهام المتأخرة: العنوان + الموظف + الموعد النهائي + كم يوم تأخير
- لون أحمر للتمييز

## ملاحظات
- كل الأرقام لازم تكون بخط `JetBrains Mono`
- البطاقات بتأثير زجاجي (`backdrop-filter: blur(12px)`)
- الرسوم البيانية ممكن تستخدم مكتبة `recharts` أو ترسمها بالـ CSS
- الصفحة لازم تكون متجاوبة — على الموبايل البطاقات تصير تحت بعض
- لما البيانات تتحمل — اعرض حالة تحميل (سكيليتون أو سبينر)
