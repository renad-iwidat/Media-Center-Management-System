# نظام التفريغ الذكي - دليل شامل

## نظرة عامة

نظام متكامل لتفريغ الصوت والفيديو وتوليد مخرجات تحريرية احترافية بشكل آلي. يستقبل النظام ملف صوت أو فيديو (من 1 إلى 60 دقيقة) ويُخرج ملفاً موحداً يتضمن ست منتجات تحريرية جاهزة للنشر.

## آلية العمل

### 1. التفريغ الصوتي
- يستخدم **OpenAI Whisper STT** للتفريغ
- دقة عالية للغة العربية
- دعم الـ timestamps

### 2. توليد المخرجات
- يستخدم **AI_MODEL** أولاً (http://93.127.132.59:8080)
- إذا فشل AI_MODEL، يتحول تلقائياً إلى **OpenAI GPT-4o**
- ضمان استمرارية الخدمة

## المخرجات المطلوبة

### 1. الملخص التنفيذي (Executive Summary)
- **الوصف**: 4-6 أسطر تبرز أهم ما ورد في المادة
- **الاستخدام**: نشر سريع على وسائل التواصل أو البريد الإخباري
- **المعايير**: دقة مطلقة في النقل، بدون إضافة أو حذف

### 2. الخبر الصحفي (News Article)
- **الوصف**: خبر مكتمل وفق بنية الهرم المقلوب
- **الاستخدام**: نشر على الموقع الإلكتروني أو التطبيقات
- **المعايير**: احترافية صحفية عالية، معلومات منسقة بشكل منطقي

### 3. التقرير الصحفي (Detailed Report)
- **الوصف**: تقرير معمّق باحترافية صحفية
- **الاستخدام**: نشر متعمق للقراء المهتمين
- **المعايير**: تحليل شامل، سياق تاريخي، تفاصيل دقيقة

### 4. منشورات سوشيال ميديا (Social Media Posts)
- **الوصف**: منشورات مع تصريحات منسوبة لقائليها
- **الصيغة**: "فلان يقول كذا..."
- **العدد**: قابل للتخصيص (افتراضي: 10)
- **الاستخدام**: نشر على تويتر، فيسبوك، إنستجرام، إلخ

### 5. مقاطع فيديو (Video Clips)
- **الوصف**: مقاطع مهمة مع تايم كود وعناوين
- **الصيغة**: `[التايم كود] - [العنوان] - [النص المرافق]`
- **مثال**: `01:04 — 02:30 - تصريح وزير الخارجية - الوزير أعلن عن قرار جديد...`
- **العدد**: قابل للتخصيص (افتراضي: 10)
- **الاستخدام**: نشر على يوتيوب، تيك توك، إنستجرام ريلز

### 6. تنبيهات سياسة التحرير (Policy Alerts)
- **الوصف**: تقرير ملخّص بأي مخالفة لسياسة القناة
- **الاستخدام**: مراجعة داخلية قبل النشر
- **المعايير**: تحديد دقيق للمخالفات، اقتراحات للتصحيح

## المعايير الإلزامية

### 1. الدقة المطلقة في النقل
- التزام تام بالكلمات والمصطلحات والمعلومات الواردة في المادة الأصلية
- ممنوع الإضافة أو الحذف أو التعديل في المعنى
- يُسمح فقط بكلمات ربط بسيطة لتحسين الصياغة دون إخلال بالمعنى

### 2. Speaker Diarization
- تمييز من قال ماذا تلقائياً
- تدريب النظام على أصوات الشخصيات المتكررة (الرئيس، الوزراء، المراسلون)
- نسب التصريحات بدقة لقائليها

### 3. سياسة التحرير
- حقل مخصص لإدخال سياسة التحرير الخاصة بالقناة
- يُدخَل مرة واحدة ويبقى قابلاً للتعديل لاحقاً
- تكون المرجعية الأولى لكل المخرجات

## البنية التقنية

### Frontend Components

#### SmartTranscription.tsx
- مكون React رئيسي للتفريغ الذكي
- الموقع: `frontend/src/components/ai/SmartTranscription.tsx`
- المميزات:
  - رفع الملفات (صوت/فيديو)
  - اختيار المخرجات المطلوبة
  - تخصيص الأرقام والمعلومات
  - معاينة المخرجات
  - تحميل الملف الموحد

### Backend Controllers

#### SmartTranscriptionController
- الموقع: `src/controllers/ai-hub/smart-transcription.controller.ts`
- الدوال:
  - `processAndGenerate`: معالجة الملف وتوليد المخرجات
  - `generateOutputs`: توليد مخرجات من نص موجود
  - `exportUnified`: تصدير الملف الموحد

### Backend Services

#### SmartTranscriptionService
- الموقع: `src/services/ai-hub/smart-transcription.service.ts`
- الدوال:
  - `generateSmartTranscriptionOutputs`: الدالة الرئيسية
  - `generateOutput`: توليد مخرج واحد
  - `extractAudioFromUrl`: استخراج الصوت من الفيديو

### API Endpoints

#### POST /api/ai-hub/smart-transcription/process
معالجة ملف صوت/فيديو وتوليد المخرجات

**Request:**
```json
{
  "fileUrl": "https://...",
  "fileType": "audio|video",
  "language": "ar",
  "outputs": [
    {
      "type": "executive_summary|news_article|detailed_report|social_media|video_clips|policy_alerts",
      "enabled": true,
      "count": 10
    }
  ],
  "editorialPolicy": "string",
  "customInfo": "string"
}
```

**Response:**
```json
{
  "success": true,
  "data": {
    "transcript": "string",
    "outputs": [
      {
        "type": "string",
        "content": "string",
        "metadata": {}
      }
    ],
    "metadata": {}
  }
}
```

#### POST /api/ai-hub/smart-transcription/generate-outputs
توليد مخرجات من نص موجود

**Request:**
```json
{
  "transcript": "string",
  "outputs": [...],
  "editorialPolicy": "string",
  "customInfo": "string"
}
```

#### POST /api/ai-hub/smart-transcription/export
تصدير الملف الموحد

**Request:**
```json
{
  "outputs": [...],
  "editorialPolicy": "string",
  "customInfo": "string"
}
```

**Response:** ملف نصي

## كيفية الاستخدام

### من الواجهة الأمامية

1. **الذهاب إلى التاب الجديد**
   - اضغط على "التفريغ الذكي" من القائمة الجانبية

2. **رفع الملف**
   - اسحب ملف صوت أو فيديو أو انقر لاختيار ملف
   - الملف يجب أن يكون بين 1 و 60 دقيقة

3. **اختيار المخرجات**
   - حدد المخرجات التي تريدها من القائمة على اليمين
   - عدّل عدد المنشورات والمقاطع حسب الحاجة

4. **إضافة معلومات إضافية**
   - أدخل سياسة التحرير الخاصة بقناتك
   - أضف أرقام أو معلومات محددة

5. **توليد المخرجات**
   - اضغط على "توليد المخرجات"
   - انتظر حتى ينتهي التوليد

6. **معاينة والتحميل**
   - معاين كل مخرج قبل التحميل
   - اضغط على "تحميل الملف الموحد" لتحميل ملف واحد يحتوي على كل شيء

### من الـ API

```bash
# معالجة ملف وتوليد المخرجات
curl -X POST http://localhost:3000/api/ai-hub/smart-transcription/process \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{
    "fileUrl": "https://example.com/video.mp4",
    "fileType": "video",
    "language": "ar",
    "outputs": [
      {"type": "executive_summary", "enabled": true},
      {"type": "social_media", "enabled": true, "count": 5}
    ],
    "editorialPolicy": "سياسة التحرير...",
    "customInfo": "معلومات إضافية..."
  }'
```

## الأداء والحدود

- **الحد الأقصى لحجم الملف**: 1 GB
- **الحد الأقصى لمدة الملف**: 60 دقيقة
- **الحد الأقصى للمخرجات**: 50 منشور/مقطع
- **وقت المعالجة**: يعتمد على طول الملف (عادة 2-5 دقائق)

## استكشاف الأخطاء

### الملف لا يتم تحميله
- تحقق من حجم الملف (أقل من 1 GB)
- تحقق من صيغة الملف (mp3, mp4, wav, إلخ)
- تحقق من الاتصال بالإنترنت

### المخرجات غير دقيقة
- تحقق من سياسة التحرير المدخلة
- تحقق من جودة الصوت في الملف الأصلي
- جرب مع ملف آخر للتأكد

### الملف الموحد لا يتم تحميله
- تحقق من أن هناك مخرجات مولدة
- تحقق من صلاحيات المتصفح
- جرب متصفح آخر
